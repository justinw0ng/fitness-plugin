# Example notes

Copy these into a vault with Atomic enabled.

**Daily note.** `daily-notes/2026-08-11.md` is the README hero note: book shelf, action buttons, a 2×2 heatmap grid, and today’s sessions. On a wide pane the heatmaps sit two-up and the shelf is a single row. The README phone frame shows the same note with three covers on one shelf.

**Dashboard.** `dashboard/Dashboard.md` belongs at `atomics/Dashboard.md` (the default **Open dashboard** path).

The blocks read session and hobby notes already in the vault. Empty heatmaps and today lists mean those notes are missing, not that the fences are wrong.

Obsidian daily notes: set the folder to `Daily notes` and paste the daily-note fences into your daily template, or copy this file and rename it to today.
