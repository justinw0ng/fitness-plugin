# Fitness

Obsidian plugin for gym and golf sessions — heatmaps, yearly dashboard, cue rollup, and quick session creation.

**Install:** download `main.js`, `manifest.json`, and `styles.css` from the latest [GitHub Release](https://github.com/justinw0ng/fitness-plugin/releases) into `<vault>/.obsidian/plugins/obsidian-fitness/`.

**Setup guide:** [docs/USER_GUIDE.md](docs/USER_GUIDE.md)
