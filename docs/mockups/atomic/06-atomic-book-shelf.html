Atomic book shelf

Plugin-rendered shelf of 3D books. Hover opens the cover (Framer Book–style rotateY(-70deg), ~600ms). Click opens the book note in Obsidian.

Command: Atomic: Open book shelf → atomics/hobbies/Reading/Book Shelf.md with atomic-bookshelf

Motion reference: Framer Book. Ship CSS 3D only (no Framer runtime). Respect prefers-reduced-motion.
