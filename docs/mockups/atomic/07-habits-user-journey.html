Step 3 · Heatmap filter

Choose all habits or a subset

atomic-heatmap defaults to every enabled habit. Pass one id or a comma list to render only those heatmaps.

```atomic-heatmap activity: all year: 2026 ``` ```atomic-heatmap activity: reading year: 2026 ``` ```atomic-heatmap activity: gym, golf, chess year: 2026 ```
